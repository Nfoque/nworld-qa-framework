# Validation

Tools and patterns for validating the E2E specs generated by the framework.

## XRay Reporter

> Origin: internal pilot — ADR 13 (E2E testing)

Custom Playwright reporter that extracts `@XRAY-{KEY}` tags from specs and uploads
results to Jira XRay (via API or JUnit XML export).

```typescript
// e2e/reporters/xray-reporter.ts
class XRayReporter implements Reporter {
  private results = new Map<string, "PASS" | "FAIL">();

  onTestEnd(test: TestCase, result: TestResult) {
    const xrayTag = test.parent.title.match(/@XRAY-(\S+)/)?.[1];
    if (xrayTag) {
      const currentStatus = result.status === "passed" ? "PASS" : "FAIL";
      const previousStatus = this.results.get(xrayTag);
      this.results.set(
        xrayTag,
        previousStatus === "FAIL" || currentStatus === "FAIL" ? "FAIL" : "PASS"
      );
    }
  }

  async onEnd() {
    // Export JUnit XML or direct call to XRay API
  }
}
```

**Status:** Full design in `xray-reporter.md`. Implementation pending.

## Verify Pipeline

> Origin: internal pilot — skill `verify`

Verification pipeline for the generated spec:

| Mode | What it runs |
|---|---|
| `quick` | lint + type-check + spec compiles |
| `full` | quick + E2E tests against mock server |

## Generated spec quality (to be defined)

Metrics to evaluate the quality of a spec generated by the framework:

1. **Real testIds** — % of `getByTestId()` calls that use IDs existing in the component
2. **Useful assertions** — % of assertions on properties (not on literal text)
3. **Flow coverage** — if Jira ACs exist, % covered by tests
4. **Compilability** — the spec compiles without TypeScript errors
5. **Runnability** — the spec passes against the mock server

**Status:** Not implemented. Depends on having generated specs to measure.
